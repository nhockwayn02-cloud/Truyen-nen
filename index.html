AI — Chỉ chạy trên GitHub Pages / Tự nhập API Key (BYOK)

GitHub Pages chỉ phục vụ file tĩnh. Không có server riêng để giấu API key. Vì vậy Muses yêu cầu bạn nhập API key trên trình duyệt. Key chỉ được lưu trong localStorage của trình duyệt và không được đưa vào file backup.

Không commit API key vào GitHub. Không gửi file backup chứa secret. Nếu dùng máy công cộng, hãy xóa key sau khi sử dụng.
